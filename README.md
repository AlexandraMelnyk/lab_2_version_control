## Опис:

Цей PR виправляє кілька проблем у класі Record:

-Перевіряє номери телефонів під час їх редагування

-Виправляє delete_phone для правильного видалення номерів

-Запобігає додаванню дублікатів номерів телефонів

-Покращує обробку помилок шляхом виникнення винятків у find_phone

Містить рефакторовані методи:
edit_phone, delete_phone, add_phone, find_phone.
